How TasteRef works

Copy a reference, paste it into your agent, and your agent does the rest.

  1. 01Copy with a shortcut

    Hover over an image or video on any site and press Option+Shift+C. TasteRef copies it with an ID strip and saves it to your vault.

  2. 02Paste into your agent

    Paste the reference into Claude Code, Codex, ChatGPT, or any agent chat that accepts images.

  3. 03Your agent designs

    The ID strip tells your agent which reference you pasted. Your agent reads the details from your vault through MCP and designs from it.

  4. 04Your agent remembers why

    Your agent records where and why it used the reference, what changed, and what you liked. It also records references you reject, with no input from you.

  5. 05Next time, paste nothing

    Start a new design task without a reference. Your agent reads your vault and designs from what you liked.

Install TasteRef with your agent

The Chrome Web Store version is not out yet. Copy this prompt and paste it into your coding agent to install TasteRef.

Install prompt 
Install TasteRef for me on this Mac. Do what you can yourself. Ask me only when needed, tell me what to click, and confirm each step before the next.

1. Check Chrome, Brave, and Ardia. Use my preferred browser if known, or ask if multiple are installed.
2. Check swiftc. If missing, run xcode-select --install and wait for me.
3. Clone https://github.com/henrikkvamme/cosmos-copy to ~/.tasteref. Keep it there for the extension and clipboard helper.
4. Run ./install.sh in ~/.tasteref to build and register the helper.
5. Load ~/.tasteref/extension unpacked (ID gdkbjkepnfmnonhgfjmklmmnboiamdad). Do this only if you control the browser or screen. Otherwise give me the path: open chrome://extensions or brave://extensions (Ardia: Settings, "Show advanced settings", Extensions), turn on Developer mode, click "Load unpacked", select the folder.
6. Have me sign in at cosmos.so (free account) in that browser.
7. Have me open the TasteRef popup, click the gear, click "Connect account", sign in with Google, click "Copy setup prompt", and paste it here for MCP. Never print, log, or share its private key.
8. Have me hover an image, press Option+Shift+C, and paste it here.

  • What your agent does

    Your agent clones the repository to ~/.tasteref and builds the clipboard helper. It registers the helper with your browser and connects to your vault.

  • What needs you

    You load the unpacked extension in Developer mode and sign in to Cosmos. Then you click Connect account in the popup and paste the setup prompt back.

  • What you need first

    You need macOS, Chrome, Brave or Ardia, and Xcode Command Line Tools. You also need a coding agent with terminal access, such as Claude Code or Codex.
